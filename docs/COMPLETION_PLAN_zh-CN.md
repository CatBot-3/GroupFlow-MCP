# GroupFlow 完整版本实施计划

本计划将“完整”定义为可在本地运行、可演示、可通过 MCP 使用并有端到端验收证据的 GroupFlow 协作版本：保留原有聚会/出行闭环，修复真实模型评测回归，支持通用模板与预设，以及长期项目中的任务、周期、资源和分阶段确认。先执行计划，再直接实现，无需逐阶段确认。

## 1. 先修正确性与评测

- 加长必要的默认工具说明和代理提示词，补回具体例子：私人便签、否定句、支持待定变更、转述退出、跨计划任务与溯源。
- 服务端对显式私人写入、否定替换值和代他人退出提供拒绝与正确恢复路径；owner 与可见性分开。
- 自动表述检查以成功产生的效果为依据，被拒的写入不能支持“已记录”。
- 摘要包含有上限的跨计划本人任务、未读事项与待决提示；按需取完整计划，允许轻量单计划自动聚焦。
- 修复公共模板元数据误报，新增私人内容误写共享范围的计数；统一 owner 任务只生成请求、不直接越权完成的评测语义。
- 修复旧修复任务覆盖新编辑的并发问题。

验收：上述失败有确定性回归测试；原有场景 API 复测，否定改值、私人意图泄露、代批准和越门提交为零；报告准确率、调用次数、总 token 和响应，保留失败原始结果。

## 2. 通用模板、预设与兼容

- 新建 gathering、trip、meeting、shared_tasks 等通用入口，保留 evening_out、study_group、general_event，增加 project。
- surprise、weekend cottage 等作为显式预设；目录只展示通用模板，规格按需加载。预设保密必须落实具体受众。
- 旧模板 ID、已存计划和旧 demo 继续解析；新计划保存模板规格版本快照，避免修改 YAML 静默改变已有计划策略。
- 默认跨度改为可理解的“计划窗口”，正整数校验；增加 bounded / ongoing 生命周期，区别计划窗口与批准有效期。
- 将具体演示场地/三天行程放入预设数据，而不是通用 trip 的默认内容。

验收：旧数据库副本可升级，旧计划正常读取；10 天 trip、普通/保密 gathering、新 YAML 发现与预设选择均有测试。

## 3. 长期项目与企业协作闭环

- 新增独立、版本化的项目数据：工作流、里程碑、结构化截止日期、工时、负责人、资源需求和成本。
- 周期任务按规则生成独立发生实例，支持近期滚动窗口、幂等展开和单次例外，不跨周期错误继承确认。
- 为项目任务增加并行资源调度：依赖 DAG、每人的工作时间、共享资源容量、已锁定/已提交安排；保留独立验证。
- 新增项目修复建议、组织者采用、受影响负责人确认、阶段授权与提交闭环。人工确认继续使用本人登录、CSRF、一次性 challenge 与内容摘要绑定；MCP 不提供批准工具。
- 工作区角色与项目审批配置区分负责人承诺和审批人授权。跨项目资源提交在事务中重检。
- 项目摘要、事项分页和工作流筛选，避免整个大项目进入模型上下文。

验收：6 周跨团队交付 demo；并行任务可行、同资源冲突被拒、依赖变更可修复、未变工作保留、旧确认不应用于新内容、无权限者不能读改或批准；周期实例和跨月日期/DST 有测试。

## 4. 前端、MCP 与可运行演示

- MCP 暴露项目配置、事项管理、分页读取、修复与发起确认的通用工具，工具说明保留必要业务契约。
- 前端提供项目/工作流/里程碑与资源安排视图；本人页面展示自己的项目确认与授权待办。
- 新增企业协作演示和脚本，覆盖变化 → 修复 → 重新确认 → 提交。
- 更新 README、工具/架构/数据说明、Demo、限制与协议证据。

验收：前端类型检查与生产构建通过，浏览器验收关键流程；真实 Streamable HTTP 工具发现和调用通过，协议保持 2025-11-25。

## 5. 评测、性能与交付

- 对说明长度做小型 API 对照，按正确性优先选择默认说明，不再用字符预算作为唯一标准。
- 原有 108 场景全量复测，新项目场景单独报告；先定位失败再修复和复测，不覆盖失败记录。
- 保留原路线型有限域求解器 16,384 组合阈值及实际后端记录；新资源调度模型单独做性能/可行性验证，不冒用旧基准结论。
- 运行完整回归与构建，检查数据迁移副本、敏感配置、产物链接与文档。

交付：可运行源码、更新的前端、项目 Demo、测试与 API 原始记录、中文完成报告和剩余外部集成边界。

## 工作方式与外部依赖边界

修改前备份源码；现有数据库使用副本验证迁移，不重置用户数据。真实模型评测沿用已配置的 DeepSeek `api.deepseek.com`，只发送合成 demo/测试场景。生产账号连接、真实 Alexa+ 客户端接入、真实预订和企业身份提供商需要外部凭据/环境；实现可配置的边界并如实标注，不把模拟执行或本地鉴权称为生产集成。
